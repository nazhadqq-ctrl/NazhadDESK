# NazhadDESK 🚀
> **سیستەمی پێشکەوتووی کۆنترۆڵکردنی کۆمپیوتەر لە دوورەوە (هاوشێوەی AnyDesk) بە کوالیتی بەرز و کۆنترۆڵی تەواو.**  
> *A high-performance, self-hosted, cross-network Remote Desktop software inspired by AnyDesk 9.*

---

## 🌟 تایبەتمەندییە سەرەکییەکان (Key Features)

* **🖥️ دیزاینی مۆدێرن هاوشێوەی AnyDesk 9:** شریتی سوور، نیشاندەری سەوز/سوور بۆ ئۆنلاین بوون، ئایدی ٩ ڕەقەمی تایبەت، و کاردەکانی دوایین پەیوەندییەکان (Recent Sessions).
* **⚡ کۆنترۆڵی خێرای ماوس و کیبۆرد (C# Native Input Injector):** جێبەجێکردنی جووڵەی ماوس، کلیکی چەپ/ڕاست، دەبڵ کلیک، سکڕۆڵ، و کیبۆرد لەڕێگەی درایڤەری ڕاستەوخۆی Win32 بە کەمتر لە **١ میلی چرکە**.
* **🌐 پەیوەندی لەسەر تەواوی ئینتەرنێت (WebRTC Global Broker):** گرێدراو بە سێرڤەری گڵۆباڵ بۆ پەیوەندی ڕاستەوخۆ لە نێوان شار و وڵاتە جیاوازەکان بەبێ پێویستی بە پۆرت فۆرواردینگ.
* **🎥 پەخشی شاشە بە کوالیتی بەرز (60 FPS Ultra-Low Latency):** پەخشی ڕاستەوخۆ بە ڕوونی تەواوی شاشە (1080p).
* **⌨ دوگمەی تایبەتی ئاسایش:** ناردنی دوگمەی `Ctrl+Alt+Del` لە دوورەوە و ناردنی دەقی درێژ و پاسۆرد بۆ سەر دیسکتۆبی بەکارهێنەر.
* **🌍 دوو زمانی:** پشتگیری تەواوی زمانی **کوردی سۆرانی (RTL)** و زمانی **ئینگلیزی (LTR)**.
* **📦 ویزاردی دابەزاندنی سەربەخۆ (Setup Wizard):** دروستکردنی شۆرتکەت لەسەر ڕووی شاشە بە شێوەی خۆکارانە.

## 🏗️ پێکهاتەی پرۆژەکە (Project Structure)

```text
NazhadDESK/
├── server.js              # سێرڤەری سەرەکی Node.js و پەیوەندییەکانی WebSockets / HTTP

├── Launcher.cs            # کردنەوەی بەرنامە لە شێوەی پەنجەرەی سەربەخۆی ویندۆز
├── NazhaDeskSetup.cs      # ویزاردی دابەزاندنی تەواو کوردی بە فۆرمی ویندۆز
├── NazhaDesk.bat          # دەستپێکردنی بەرنامەکە بە یەک کلیک لە ویندۆز
├── public/                # ڕووکاری سەرەکی بەرنامەکە
│   ├── index.html         # پەڕەی سەرەکی و دیزاینی AnyDesk
│   ├── style.css          # ستایڵی مۆدێرن و ڕەنگەکانی ئەنیدیسک
│   ├── app.js             # لۆجیکی WebRTC، گواستنەوەی فەرمانەکان و زمان
│   └── peerjs.min.js      # کتێبخانەی جیهانی پەیوەندی WebRTC
└── README.md
```

## 🛠️ چۆنیەتی دامەزراندن و کارپێکردن (Getting Started)

### داواکارییەکان:
* [Node.js](https://nodejs.org/) (وەشانی ١٨ یان بەرزتر)
* کۆمپیوتەری ویندۆز ١٠ یان ١١

### هەنگاوەکان:
1. داگرتنی پرۆژەکە لە ڕێگەی Git:
```bash
git clone https://github.com/nazhadqq-ctrl/NazhadDESK.git
cd NazhadDESK
```

2. دابەزاندنی پاکێجەکان:
```bash
npm install
```

3. کارپێکردنی بەرنامەکە:
```bash
node server.js
```
پاشان بچۆ سەر ئەم ناونیشانە لە وێبگەڕەکەتدا:
👉 `http://localhost:9090`

## 🔒 پاراستن و متمانە (Security)
* هەموو پەیوەندییەکانی شاشە و دەنگ لەڕێگەی پرۆتۆکۆڵی پارێزراوی **WebRTC DTLS/SRTP (End-to-End Encrypted)** دەگوازرێنەوە.
* هیچ دانیشتنێک دەستپێناکات تا بەکارهێنەری بەرامبەر کلیک لەسەر دوگمەی قبوڵکردن (**Accept**) نەکات.
